# 简历模板1设计文档

## 模板概述

这是一个简洁现代的简历模板，采用单栏布局，包含以下模块：
- 个人信息模块（含头像）
- 求职意向模块
- 工作经历模块
- 教育经历模块
- 项目经历模块
- 专业技能模块
- 自我介绍模块

整体设计风格简洁明快，使用蓝色作为主色调，白色背景，灰色作为辅助色。

## 布局规格

- 页面尺寸：A4 大小（210mm × 297mm）
- 边距：左右边距 20mm，上下边距 15mm
- 模块间距：15mm
- 行高：1.5 倍行高

## 颜色规范

- 主色调：蓝色（#1677ff）
- 次色调：深蓝色（#0958d9）
- 文本主色：黑色（#000000）
- 文本辅助色：灰色（#666666）
- 文本浅色：灰色（#999999）
- 背景色：白色（#ffffff）
- 边框色：浅蓝色（#e6f2ff）

## 字体规范

- 标题字体：16px，粗体
- 二级标题字体：14px，粗体
- 三级标题字体：13px，粗体
- 正文字体：12px，常规
- 字体类型：无衬线字体（如 Arial 或 system-ui）

# 创建一个新的简历模板

## 原则
1. 参考现有的经典模板，确保新模板具有一致的设计风格和布局（左边展示模板，右边展示编辑区域）。
2. 确保新模板包含所有必要的简历部分，如个人信息、教育背景、工作经历、技能等。
3. 确保编辑区域的输入框和组件能够正确地绑定到模板中的相应部分，编辑组件的操作逻辑正确无误。
4. 在不同设备和屏幕尺寸，直接按比例缩放简历模板区域，编辑区域要有相应的响应式设计。

## 工作流程

### 一、设计新模板
获取 $ARGUMENTS 中的内容，如果有图片、文件、设计稿，参考图片、文件、设计稿进行新模板的设计和布局规划；
如果没有图片或者设计稿，按照用户需求搜索相关的简历模板图片，参考这些图片进行新模板的设计和布局规划。
确保新模板的设计风格与现有模板一致，并且满足用户的需求和期望。

### 二、实现新模板
1. 创建新的模板组件，命名为 $ARGUMENTS[0]，参考现有项目结构，在对应的目录下创建新的组件文件。
2. 按照步骤一中生成的设计和布局规划实现新的简历模板。

### 三、验证新模板
调用 chrome-devtools 进行调试，确保新模板的布局和功能符合预期。
1. 验证新模板的布局是否正确，确保各个部分（个人信息、教育背景、工作经历、技能等）都正确显示。
2. 验证编辑区域的输入框和组件是否正确绑定到模板中的相应部分，确保编辑组件的操作逻辑正确无误。
3. 验证新模板的响应式设计，确保在不同设备和屏幕尺寸下都能正确显示和使用。
4. 验证 保存、导入、导出PDF 等功能是否正常工作.
